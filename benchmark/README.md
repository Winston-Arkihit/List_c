# Сравнение списка и массива

Здесь находятся две отдельные программы с одинаковым смешанным тестом.
Контейнер сначала заполняется 200000 целыми числами. Затем каждый из 1000
тестов выполняет 100 пар операций «удалить элемент из середины + вставить его
обратно», после чего полностью обходит контейнер и считает сумму.

Для списка позиция задана известным индексом узла (аналог итератора), поэтому
удаление и вставка меняют только связи. Для массива та же операция требует
сдвига правой половины элементов. Время измеряется стандартной библиотекой
`<time.h>`. Первичное заполнение не входит в измеряемый участок, но все
удаления, вставки и обходы входят.

Сборка с оптимизацией:

```powershell
gcc -O2 -std=c11 -Wall -Wextra -pedantic list_benchmark.c -o bin/list_benchmark.exe
gcc -O2 -std=c11 -Wall -Wextra -pedantic array_benchmark.c -o bin/array_benchmark.exe
```

Запуск:

```powershell
.\bin\list_benchmark.exe
.\bin\array_benchmark.exe
```

Поле `Checksum` у программ должно совпасть. Оно не позволяет компилятору
удалить вычисления как неиспользуемые. Основной показатель для сравнения —
`Total time`; сравнивать следует одинаковые запуски обеих программ.
